Observed latency: 10008ms

NOTE: because node:sqlite is synchronous, a slow datastore call blocks
the entire event loop -- ALL other in-flight requests to this process
queue up behind it, not just the one that hit the slow call. This is a
real, honest limitation of the single-threaded synchronous design; see
README 'Known Limitations' and DECISIONS.md.


=== Phase 2b: prove the slow call blocks OTHER concurrent requests too ===
(this is the important part -- it's not just the one unlucky request that pays the cost)
  request A (triggers the slow path): 3008ms
  request B (arrives 100ms later, completely unrelated buyer): 5908ms
  (B was delayed almost as long as A despite sharing nothing with it -- the synchronous
   datastore call blocks Node's single event loop thread entirely.)
